# 此知识目录的使用约定

- 本目录是通用空白模板。目录名称、标题、字段、占位符和模板说明不是用户事实，不自动补填个人资料。
- 仅按当前任务读取相关已有文件。区分本人明确陈述、第三方资料、推测和待确认信息。
- 仅在用户明确要求维护本机 Markdown 时创建或修改记录；保留无关文件和已有用户内容。
- 候选记忆只使用三字段摘要格式：`summary`、`kind`、`source`；真人确认和正式保存由当前集成的确认流程处理。
- 不自动上传或导入本目录，不把路径映射视为远端内容已经存在，不上传聊天原文或工具日志。
- 不将凭据、密钥、证件号码或金融账号写入本目录。记录与归档请参考[记录规范](记录规范.md)。
