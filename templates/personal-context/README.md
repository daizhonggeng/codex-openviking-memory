# 个人知识目录模板

这是全新的通用目录骨架，没有预填个人资料。目录、标题、空白字段和记录示例都不构成个人事实。

三个核心文件分别用于明确确认的个人档案（[PROFILE.md](PROFILE.md)）、长期偏好（[PREFERENCES.md](PREFERENCES.md)）和近期重点（[CURRENT.md](CURRENT.md)）。其余目录按主题导航；先读[记录规范](记录规范.md)，再按实际需要使用[空白记录模板](90-模板/README.md)。

- [03-家庭与亲密关系](03-家庭与亲密关系/README.md)：按需组织家庭事项和共同计划，尊重相关人员隐私。
- [04-亲友与社交](04-亲友与社交/README.md)：整理经授权记录的关系事项、往来安排与社交复盘。
- [05-身心健康](05-身心健康/README.md)：组织本人主动记录的健康、运动与日常习惯资料。

- [07-财务与资产](07-财务与资产/README.md)：按需整理预算、财务目标和非敏感事项；不存放账号、卡号或凭据。
- [08-学习与知识](08-学习与知识/README.md)：组织学习计划、可复用知识与资料入口，保留必要来源。

## 与 OpenViking 的关系

本机 Markdown 目录是可选的导航与记录模板；初始化与路径映射都不会上传、导入或同步资料。模板文件与目录的相对路径可以映射到配置用户的 `resources/personal-context/` 资源层级；经确认提取的简短原生记忆位于独立的 `memories/` 层级。路径映射不表示远端文件已经存在。

普通对话只在当前任务需要时读取相关已有信息。候选摘要仍使用 `summary`、`kind`、`source` 三个字段；模板不会自动写入 Markdown，也不会替代真人确认。安装或再次初始化时会保留已有常规文件，新增缺失的模板文件。
